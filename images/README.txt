This folder holds image assets for the portfolio site. 

Place your image files in the following subfolders (create them if they don't exist):

- images/hero/
- images/paintings/
- images/illustrations/
- images/projects/
- images/events/
- images/testimonials/

Naming conventions used in the template JSON (data/site-data.json):
- paintings: images/paintings/painting-01.jpg, painting-02.jpg, ...
- sketches: images/illustrations/sketch-01.jpg, ...
- colored: images/illustrations/colored-01.jpg, ...
- projects: images/projects/project-01.jpg, ...
- events: images/events/event-01.jpg, ...
- testimonials: images/testimonials/person-01.jpg, ...

After adding images, the site will load them automatically from data/site-data.json. Commit new files with the same paths to the repository.
